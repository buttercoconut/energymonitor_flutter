# Energy Monitor Flutter App

This repository contains the Flutter frontend for the Energy Monitor application. It follows a Clean Architecture approach with separate layers for UI, domain, and data.

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run the app
flutter run
```

## Project Structure

```
lib/
├── models/          # Data models
├── services/        # API and data services
├── providers/       # State management
├── widgets/         # Reusable UI components
├── screens/         # Page-level widgets
├── utils/           # Utility classes
└── main.dart        # App entry point
```
